# Hi, I'm Corbin 👋

I'm an Associate Inventory Manager in Lehi, Utah, and a BYU Economics grad. At work I run demand forecasting and purchasing. In my spare time I build tools for forecasting, automation, and machine learning, mostly with Python, SQL, and AI coding tools like Claude and Cursor.

## Featured projects

- **[CapScout](https://github.com/corbinsz/CapScout)**: a local Streamlit app that grades a home as a short-term rental. It predicts the nightly rate with a ridge regression trained on 20,700+ cleaned Airbnb listings in Austin, San Diego, and Seattle. On 3,600+ homes in map areas held out of training, it had 37% less average error than the local median nightly rate. A daily calendar collector is set up to gather availability data so a later model can learn real booked nights.
- **[AI Outreach Automation](https://github.com/corbinsz/ai-outreach-automation)**: a Python and Streamlit tool that reads a company's website, has Claude draft a tailored email, and sends it from Gmail only after you review and confirm it. It runs offline with one command and has 121 automated tests.
- **[Demand Planning Platform](https://github.com/corbinsz/demand-planning-platform)**: a FastAPI and React app that forecasts SKU demand with Holt-Winters, flags stockouts, and suggests purchase quantities using a made-up sample catalog. It includes a forecast-accuracy backtest against a seasonal-naive baseline.
- **[Portfolio site for a friend](https://github.com/corbinsz/SteveWebsite)**: a responsive multi-page HTML/CSS/JS portfolio I built for an ASU mechanical engineering student.

The apps run locally with Docker or a single setup command, and none of them are hosted.
